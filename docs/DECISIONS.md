## สรุปการโต้วาที

ทั้งสามมุมเห็นตรงกันว่าตัวตน "valentine · Carry · Phantom Assassin · ฟาร์มเงียบแล้วปิดเกม" ชัดและเข้ากับธีมดำ/แดงเบอร์กันดี แต่ headline เคลมเกินจริงด้วยคำว่า "โปรเพลเยอร์" ซึ่งไม่ตรงกับ Bio
UX Critic ชี้ว่าข้อมูลพร้อมแค่ครึ่งทาง: Home/About ติด parser (L2), Interests ซ้ำกับ Home, Contact ไม่มีปลายทางจริง และ Guestbook ขึ้น nav ทั้งที่ API ยังไม่พร้อม
Devil's Advocate เตือนว่าความเสี่ยง privacy ใหญ่สุดคือข้อมูลที่ "ต่อกันได้" (Bio + นามแฝง + URL/repo) มากกว่าสิ่งที่เว็บแสดงตรง ๆ และ Must หลายข้อแตกเป็นงานข้าม owner
ข้อสรุปคือ v1 ให้เล็กลง: Hero + About มุม B + Interests ที่ลึกกว่า Home + Contact ฟอร์มเดิม โดยตัด Rank Journey และ Guestbook ออกจากรอบแรก

### การแก้ `docs/PROFILE.md` ในรอบนี้

- `## Headline` — เดิม "โปรเพลเยอร์ Dota 2 สาย Carry — ฟาร์มในเงามืด แล้วปิดเกมในจังหวะเดียว" → "Carry สาย Phantom Assassin · กำลังไต่สู่ Immortal" (D1)
- เพิ่ม `## Tagline` — "ฟาร์มในเงามืด แล้วปิดเกมในจังหวะเดียว" (D1 · parser ปัจจุบันยังไม่อ่านหัวข้อนี้ — Lab 04 ต้องรองรับ)
- `## Tone` — เพิ่มบรรทัด "กติกาเสียงบนเว็บ" (D3)
- **ไม่ได้แก้** Bio / Contact / Brainstorm — Bio เวอร์ชันเว็บตาม D9 ให้เจ้าของเขียนใหม่ ไม่ให้ agent แต่งแทน

## สิ่งที่เลื่อนออก (Out of scope v1)

- Guestbook ทั้งหน้า UI และ API (D5)
- Rank Journey แบบแถบความคืบหน้า (D6)
- ช่อง "เรื่อง" ในฟอร์ม Contact (ชวนปาร์ตี้ / ชวนแข่ง / งาน) (D7)
- Achievements แบบการ์ด — รวมถึงบรรทัด "แชมป์รายการโรงเรียน" จนกว่าจะตอบได้ว่าไม่โยงตัวตน (D9)
- คลิปไฮไลต์ / ลิงก์สตรีม · หน้า Setup · สถิติอัตโนมัติจาก API ภายนอก
- login · ระบบจับคู่ปาร์ตี้ · leaderboard · CMS บล็อก · หลายภาษา
